# Расчётно-графическая работа (4 семестр)

**Компилятор** учебного языка программирования на **C++**: лексический анализ, построение LR-таблицы по грамматике и синтаксический разбор.

## Исходный код:

` main.cpp ` — точка входа: чтение файла, вызов лексера и синтаксического анализатора;

` lexer.cpp ` / ` lexer.h ` — лексический анализатор;

` grammar.cpp ` — работа с грамматикой и LR-таблицей;

` syntax.cpp ` — синтаксический анализ (GPP);

` tokens.h `, ` lexems.h `, ` string_utils.cpp ` — типы лексем и вспомогательные функции;

## Каталоги:

` data ` — файлы грамматик (` grammar.txt ` и др.) и список ключевых слов;

` inputs ` — примеры исходных программ на учебном ЯП;

` outputs ` — результаты работы: таблицы разбора, списки токенов, LR-таблица;

` euler.txt `, ` input1.txt ` — дополнительные тестовые входы в корне;

**Связь с 3 семестром:** лексический анализатор из ` RGR_3_sem ` был основой для этой работы.
