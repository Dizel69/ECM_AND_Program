# Задание 4 — код на ассемблере (MARS)

Лабораторная по архитектуре ЭВМ: программы на **MIPS-ассемблере** для симулятора *Mars*.

` helloworld.asm ` — пример «Hello, World»;

` io.asm ` — ввод-вывод;

` 3.asm `, ` 7.asm `, ` 8.asm `, ` 10.asm ` — варианты заданий;

` 3.txt `, ` 7.txt `, ` 8.txt `, ` 10.txt ` — условия или тестовые данные к соответствующим `.asm` файлам;
