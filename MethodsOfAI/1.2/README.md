# 1.2. Печатный текст на фотографии

Главный файл — `recognize.py`. В начале укажите путь в переменной `IMAGE`, затем из этой папки:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python recognize.py
```

В терминал печатаются найденные строки.

Программа читает готовую модель PP-OCR через библиотеку `rapidocr`. Веса лежат в `models/` и после первой загрузки берутся с диска. Если папки `models/` нет, библиотека скачает её один раз при запуске, для этого нужен интернет. Дальше сеть не нужна.

В гит не входят `.venv`, `models/` и фотографии: это не код, а гит считает их как тысячи строк. Свои снимки кладите в `photos/` и прописывайте путь в `IMAGE`.
