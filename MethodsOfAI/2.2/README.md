# 2.2. Транскрибация аудио с несколькими языками

Главный файл — `transcribe.py`. В начале укажите путь в переменной `AUDIO`, затем из этой папки:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python transcribe.py
```

В терминал печатаются фрагменты: время, язык и текст. Язык на весь файл не задаётся. Запись режется по паузам, и для каждого куска язык определяется отдельно, поэтому в одной записи могут идти русский, английский и другие языки. Между разными языками нужна пауза около секунды: без неё кусок останется на языке, с которого начался. В перевод речь не переводится.

Это готовая модель Whisper (`small`) через библиотеку `faster-whisper`. Веса лежат в `models/` и после первой загрузки читаются с диска. Если папки нет, библиотека скачает её один раз, для этого нужен интернет.

В гит не входят `.venv` и `models/`. Свой файл положите рядом и пропишите путь в `AUDIO`. Пример смешанной записи: `audio/several_languages.wav`.
