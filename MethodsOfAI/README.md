# Методы ИИ

Команды ниже копируются из этой папки.

Выйти из окружения:

```bash
deactivate
```

Активировать окружение 1.2 и запустить программу:

```bash
source 1.2/.venv/bin/activate
python 1.2/recognize.py
```

Активировать окружение 2.2 и запустить программу:

```bash
source 2.2/.venv/bin/activate
python 2.2/transcribe.py
```
