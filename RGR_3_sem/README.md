# Расчётно-графическая работа (3 семестр)

Один файл ` rgr.cpp ` содержит **две части**:

1. **Первая РГР** — структуры данных: разреженная булева матрица (` BoolMatrix `), итератор, операции над матрицами;
2. **Вторая РГР** — **лексический анализатор** на конечном автомате: разбор входного текста на лексемы (ключевые слова, операции, переменные, булевы матрицы и т.д.). Этот анализатор затем используется в ` RGR_4_sem `.

` input1 ` … ` input8.txt ` — тестовые входные данные для проверки программы;
