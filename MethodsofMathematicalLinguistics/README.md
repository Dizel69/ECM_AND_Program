# Программы по предмету *«Методы математической лингвистики»*

` algorithm_erly.py ` — интерактивная проверка слов **алгоритмом Эрли** по контекстно-свободной грамматике из файла ` grammar_erly.txt `;

` algorithm_portera.py ` — **стемминг** английских слов по алгоритму Портера (приведение словоформ к общей основе);

` grammar_erly.txt ` — описание грамматики для парсера Эрли;
