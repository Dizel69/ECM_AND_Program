# Программы по предмету *«Количественные методы в маркетинге»*

Основной язык — **R**. Скрипты строят модели временных рядов (ARIMA), проверяют адекватность прогнозов и применяют статистические критерии.

## Корневые файлы:

` main.R ` — главный сценарий: подбор ARIMA, проверка адекватности, графики;

` ARIMA.R `, ` AutoArima.R ` — подбор и оценка моделей ARIMA;

` AdequacyCheck.R ` — тесты адекватности остатков модели;

` data.csv `, ` resid.csv ` — данные временного ряда и остатки;

## Папки с заданиями:

` ConstMeanTest ` — t-тест постоянного среднего;

` VarianceConstTest ` — F-тест равенства дисперсий;

` MedianCriterion ` — критерий медианы;

` UpAndDownCriteria ` — критерий пиков и впадин;

` ChekingTheAutocorrelOfResid ` — проверка автокорреляции остатков;

` TimeSeriesForecastingWithARIMA ` — прогнозирование ряда с ARIMA;

` data ` — CSV-файлы с выборками для расчётов;

` RESULTS ` — сохранённые текстовые отчёты по результатам (` Result1 `, ` Result2 `);
