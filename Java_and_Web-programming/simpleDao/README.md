# simpleDao

Веб-приложение **«Блокнот баллов»** на Spring Boot: очередь задач, журнал, сумма баллов, H2 или PostgreSQL.

` src/main/java/w2l/inspired/ ` — код приложения (контроллеры, сервис, JPA);

` src/main/resources/templates/notebook.html ` — веб-интерфейс;

` Dockerfile ` — образ для Docker Compose из корня ` Java_and_Web-programming `;

Подробнее — в ` README.md ` родительской папки.
