# Расчётно-графическая работа (2 семестр)

Программа на языке **C** — поиск слова в текстовом файле методом **Фибоначчи**.

` rgr.c ` — основной исходный код (функция ` fibSearch `, сравнение строк и чисел);

` tuta ` — тестовый файл со словами для проверки поиска;

**Запуск:** `./rgr <файл> <слово>` — в аргументах передаётся имя файла и искомое слово.
