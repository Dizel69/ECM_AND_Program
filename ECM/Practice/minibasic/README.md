# minibasic

Учебный **компилятор языка MiniBasic** (4 семестр практики): лексический и синтаксический анализ, таблицы строк и операндов, генерация кода.

## Основные файлы:

` MINI_BASIC_lexer.cpp ` — лексический анализатор;

` MINI_BASIC_syntax.cpp ` — синтаксический анализатор;

` hash.cpp `, ` lexerrdef.h ` — хеш-таблица идентификаторов и коды ошибок;

` program.asm `, ` samopor.asm ` — примеры сгенерированного кода;

` lexer_data.txt `, ` syntax_data.txt ` — тестовые данные для разбора;

` test.txt `, ` o1.txt `, ` o2.txt `, ` cringe.txt ` — входные и выходные примеры;

` minibasic.vcxproj ` — проект Visual Studio;

## Документация и вспомогательное:

` info ` — материалы по лексическому анализу (хеширование, цепочки, тесты);
