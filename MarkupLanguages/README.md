# Здесь собраны лабораторные по предмету *«Языки разметки»*

Работы оформлены в **LaTeX**. Для сборки PDF нужен дистрибутив TeX (например, TeX Live) и компилятор `pdflatex`.

## Задания:

` 1Task ` — базовые формулы и окружения LaTeX (задание 5);

` 2Task ` — типографические приёмы: цвет, подчёркивание, колонки, коммутативные диаграммы;

` 3Task ` — графические приёмы: таблицы, TikZ, вставка изображений (` images ` — картинки для отчёта);

` 4Task ` — лабораторная по TikZ (схемы и рисунки на чистом TikZ);
