# В директориях содержатся различные программы:

1. `ArchitectureECM` — программы по предмету *Архитектура ЭВМ;*

2. `ECM` — программы по предмету *Практикум на ЭВМ:*
    * Программы *модулей;*
    * Программы *контрольных работ;*
    * Программы *учебной практики;*
    * Программы *пересдач;*

3. `FunctionalAnalysis` — программа по предмету *Функциональный анализ,* написанная Владиславом Станкевичем;

4. `ModelSocPro` — программа по предмету *Моделирование социальных процессов,* которая делает прогноз на основе данных и говорит, какой метод самый лучший;

5. `Nonparametric Statistics` — программы по предмету *Непараметрическая статистика;*

6. `NumericalMethods` — программы по предмету *Численные методы;*

7. `OperationSystem` — программы по предмету *Операционные системы;*

8. `ComputerNetwork` — программы по предмету *Компьютерные сети;*

9. `ComputerGraphics` — программы по предмету *Компьютерная графика;*

10. `MathPakages` — программы по предмету *Применение математических пакетов в решении прикладных задач;*

11. `DataBase` — программа по предмету *Базы данных;*

12. `MarkupLanguages` — работы по предмету *Языки разметки* (LaTeX, TikZ);

13. `MethodsofMathematicalLinguistics` — программы по предмету *Методы математической лингвистики;*

14. `Java_and_Web-programming` — веб-приложение по предмету *Java и веб-программирование* (Spring Boot, «Блокнот баллов»);

15. `TestAutomationCourseTemplate` — шаблон курса по *автоматизации тестирования* (Playwright, PyTest);

16. `RGR_2_sem` — расчётно-графическая работа: *поиск Фибоначчи;*

17. `RGR_3_sem` — расчётно-графическая работа: *лексический анализатор,* который потом используется в `RGR_4_sem`;

18. `RGR_4_sem` — расчётно-графическая работа: *компилятор* выдуманного языка программирования (ЯП);

19. `QuantitativeMethodsInMarketing` — программы по предмету *Количественные методы в маркетинге;*
